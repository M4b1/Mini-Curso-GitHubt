**Meus Comandos Mais Usados (Cheat Sheet)**
* `git init`: Inicia o repositório local.
* `git status`: Verifica o estado atual dos arquivos modificados.
* `git add .`: Prepara todas as alterações para o commit.
* `git commit -m "mensagem"`: Salva a alteração na linha do tempo.
* `git push`: Envia o código para o GitHub.
